# SuperMimic 复现

复现 SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model（CoRL 2026, arXiv:2610.28480）在 Unitree G1 上的全身动作跟踪，并在观测里补了一组参考锚点，把长片段上的全局漂移压下去。

LAFAN1 全量 40 条片段、论文评测口径下：基线 28k 轮归一化回报 0.5715、失败 8 条；加锚点观测后同配置 0.850，失败 2 条，朝向从 7 s 撑到 44 s 以上。

演示视频：

- `media/showcase.mp4` — 基线策略，后段能看到全局朝向漂移
- `media/showcase_anchor.mp4` — 加锚点观测后的整段回放，画面上标了每条片段的归一化回报

基线那段后段的漂移就是下面在分析的东西，见 [漂移诊断](#漂移诊断)。

## 结果

40 条整条片段，确定性评测，无噪声、无域随机化（论文 Appendix F 口径）。归一化回报满分 1。

| 配置 | 轮数 | 回报 | 失败片段 | 朝向保持（中位） | 世界系速度奖励 |
|---|---|---|---|---|---|
| 基线（论文观测） | 28k | 0.5715 | 8 / 40 | 7.4 s | 0.115 |
| 加锚点观测（run A） | 28k | 0.8504 | 2 / 40 | 75.5 s | 0.876 |
| 加锚点观测（run B） | 28k | 0.8630 | 3 / 40 | 44.4 s | 0.839 |
| 加锚点观测（run B 续训） | 56k | 0.8961 | 4 / 40 | 59.2 s | 0.912 |

同配置加锚点，回报 +0.28。同配置跑两次的差是 0.0126，失败数差 1–2 条，所以这个幅度不用怀疑是噪声。

28k 到 56k 只多 0.033，约为噪声的两倍多；失败数 3 → 4 落在噪声内，不算提升。

「朝向保持」是全局朝向误差超过 15° 之前的时长。这是重尾统计量，同配置两次跑出 75.5 s 和 44.4 s，只能做量级比较。

训练侧：单卡 RTX 5090、4096 环境、35.7k 轮、约 3.6 小时，策略回报收敛到 0.730，世界模型 8 步开环误差 0.0162（一步 0.0088）。

## 观测里缺的东西

论文的策略观测（Table A.1）只有本体感知：关节位置与速度、躯干角速度，以及参考动作的关节量和相对朝向。奖励（Table A.2）里有两项直接打在根位姿的位置和朝向上，评测又是整条 episode。

策略看不到全局根位姿，却要对它的误差负责。这部分误差不会随着训练更久而消失，只会在整条片段上攒成漂移，长片段上先丢的是朝向。

## 锚点观测

观测里加了 9 维：

```
ξ = [ p_ref − p_robot ,  R_err 的前两列 ]   ∈ R^9
```

前 3 维是参考锚点在机器人锚点系下的位置误差，后 6 维是旋转误差矩阵的前两列。参考轨迹里这个量现成就有，真机上也不需要额外传感器。

其余配置逐项不动：4096 环境、policy batch 4096、`total-iterations` 320000、`max-hours` 停机、seed 0。

## 漂移诊断

`scripts/diag_drift.py` 逐条片段记录全局位姿误差，并把机器人速度按朝向误差旋转到世界系之后再算一次速度奖励。

| 模型 | xy 超限（中位） | 朝向超限（中位） | 速度奖励（世界系 → 按朝向对齐） |
|---|---|---|---|
| 基线 28k | 8.46 s | 7.42 s | 0.115 → 0.862 |
| 锚点 28k | 23.80 s | 75.52 s | 0.876 → 0.878 |

基线那行两个数差得远：世界系奖励 0.115，对齐朝向之后 0.862。差别在朝向，不在局部跟踪。

锚点那行两个数基本一样，说明这个量已经不再被漂移拖累。

## 抗扰

`scripts/eval_push.py`：静态 T-pose 参考，256 环境，1 s 时给骨盆加一个水平速度，统计摔倒比例。

| 推力 | 摔倒率 |
|---|---|
| 0.5 / 1.0 / 2.0 m/s | 0% |
| 4.0 m/s | 68.75% |

## 评测协议

- 数据：LAFAN1 Retargeting Dataset 的 G1 版本，40 条片段、2.451 h，重采样到 50 Hz
- 片段：每条完整跑一遍，从第 0 帧起，确定性策略，不加观测噪声和域随机化
- 失败判据：沿用训练终止条件，高度偏离 0.25 m 或倾斜超过 0.8
- 指标：归一化回报（各项奖励按每步上限归一后求和）、失败条数、失锁时间、速度奖励
- 噪声底：同配置两次独立 run 回报差 0.0126、失败数差 1–2 条

评测和诊断脚本跑在 mjlab / MuJoCo-Warp 的训练栈上，训练栈没有放进这个仓库。结果数据在 `results/` 下，上面的表可以直接复算。

## 复现

- 数据：40 条 CSV 用向量化 slerp 加 CPU MuJoCo 正运动学转到 50 Hz npz
- 训练：4096 并行环境，policy batch 4096。`total-iterations` 同时也是余弦退火的基准，所以保持默认 320000，用 `max-hours` 停
- 评测：40 条整条、确定性、无噪声、无域随机化

```bash
python scripts/eval_benchmark.py --ckpt logs/lafan1/ckpt_0028000.pt --npz-dir data/npz/lafan1
python scripts/diag_drift.py     --ckpt logs/lafan1/ckpt_0028000.pt --npz-dir data/npz/lafan1
python scripts/eval_push.py      --ckpt logs/lafan1/ckpt_0028000.pt
```
